# 隐私与安全说明

> 你直接问的问题：「这软件会泄露我的隐私吗？会对手机安全造成危害吗？」
> 下面按**可核查**的方式回答：先给结论，再给数据流向、代码位置、自查方法，最后说清风险。

## 一、结论

| 问题 | 结论 |
|---|---|
| 会上传我的音频吗？ | **不会**。语音识别完全在本机用 whisper.cpp 跑，音频不离开手机 |
| 会偷录我的屏幕吗？ | **不会**。虽然申请了"录屏授权"，但代码**从未创建 VirtualDisplay**，也就是从来没读取过任何一帧画面。这个授权只是安卓规定的"抓播放音频"的前置条件（`AudioPlaybackCapture` 必须挂在 `MediaProjection` 上） |
| 会上传我的数据吗？ | **只有识别出的文字**，且**只发给你自己配置的翻译 API**。你不填 API，就一个字都不发 |
| 有广告 / 统计 / 第三方 SDK 吗？ | **没有**。依赖为空（见 `app/build.gradle.kts` 的 `dependencies {}`），全是平台 API |
| API Key 安全吗？ | 存在你手机的应用私有目录（`SharedPreferences`，**明文**）。不出手机，但 root / 备份能读到——建议用**低额度、可随时吊销**的 key |

## 二、它具备的能力与对应权限（逐个说明用途）

| 权限 / 能力 | 用途 | 不做的事 |
|---|---|---|
| `RECORD_AUDIO` | 抓取"正在播放的音频"的必要条件 | 不后台偷录麦克风（本项目不读麦克风） |
| `FOREGROUND_SERVICE` + `..._MEDIA_PROJECTION` | 让捕获能长时间在前台运行，并显示常驻通知 | 通知无法隐藏，你随时能看到它在跑 |
| `SYSTEM_ALERT_WINDOW` | 画悬浮字幕 | 不读取你屏幕上其他内容 |
| `POST_NOTIFICATIONS` | 显示前台服务通知与"停止同传"按钮 | — |
| `INTERNET` | ① 下载识别模型 ② 调用你配置的翻译 API | 不做任何其他联网 |

## 三、数据流向（哪一步、什么东西、去哪里）

| 环节 | 数据 | 去向 |
|---|---|---|
| 采集 | 手机内播放的 PCM 音频 | **只在本机内存里**，不落盘、不上传 |
| 识别 | 音频 → 文字 | 本机 CPU（whisper.cpp）。模型文件也在本机 |
| 翻译 | **识别出的文字** | → 你在设置页填的那个 API 地址（默认示例是 DeepSeek）。这是**唯一**的数据出口 |
| 设置 | API Key / 地址 / 模型名 / 字号 / 字幕位置 | 本机 `SharedPreferences` |
| 模型下载 | 只有你点"下载"时才发生 | `huggingface.co`，失败自动换 `hf-mirror.com` |
| 日志 | 运行日志 | 只显示在 App 界面里，不落盘、不上传 |

**想验证"不联网也能用"**：把设置页的 API Key 留空 → 除了点"下载模型"，全程零联网也能出字幕（第二行=第一行）。

## 四、你可以自己核实

1. **看代码**（都在你自己的仓库里，我没有任何隐藏后端）：
   - 唯一发起网络请求的两个文件：`pipeline/ModelStore.kt`（下载模型）、`pipeline/Translator.kt`（翻译 API）
   - 安装一个防火墙类 App（如 NetGuard 等），只允许"离线同传"访问你的 API 域名，观察它是否只连那一个地址
   - 搜索整个工程里 `http` 的出现位置：你会只看到上面那两处的域名
2. **看系统提示**：抓取期间安卓会强制显示"屏幕共享中"胶囊 + 常驻通知。**停止后两者都消失**——这是最直观的证据。
3. **看悬浮窗**：字幕只显示识别/翻译文本，不显示任何其他屏幕内容。
4. **看依赖**：`app/build.gradle.kts` 的 `dependencies {}` 是**空的**，没有统计 SDK、没有广告 SDK。

## 五、必须告诉你的真实风险

1. **这是自签名（debug）应用**，不是应用商店审核过的版本。请只从**你自己的仓库**安装；**不要把这个 APK 转发给别人**——它具备"捕获播放音频"的能力，落在别人手里等于把能力也给了别人。
2. **API Key 是明文存储**的（应用私有目录）。任何能 root 或能读应用数据的工具都能拿到它。建议：单独申请一个 key、设低额度、随时能在服务商后台吊销。
3. **CI 里的 debug 签名**缓存在你 GitHub 仓库的 Actions 缓存中，只有你的仓库能读。若这个 keystore 泄漏，别人可以签出"能覆盖安装在你手机上"的包。如果你在意，可以删掉 workflow 里的缓存步骤，代价是每次升级都要先卸载。
4. **它能抓到其他 App 的音频**（只要是允许被捕获的）。这本身就是敏感能力——安卓的做法是**每次都必须你手动点同意录屏**，不会静默开启。请留意这一条系统提示。
5. **发热是真问题**（v0.7 已优化）：持续推理会让手机变烫，长期高温对电池有损耗。所以默认关掉了临时字幕，并在系统报"偏热"以上时自动降载。

## 六、彻底关闭它

1. App 里点 **停止**（或通知栏"停止同传"、系统"停止共享"）
2. 不再使用 → 卸载
3. 想更彻底：系统设置里撤销"录音""显示在其他应用上层"权限
4. 想清数据：设置页保存的内容都在应用私有目录，卸载即清空
