# 音频捕获限制（AudioPlaybackCapture）笔记

本篇只讲一件事：**为什么"抓手机内播放的声音"不是写代码就能解决的**，
以及怎么用最小成本先验证。

## 1. 机制

安卓要抓"别的 App 正在播放的音频"，只有一条正统路径：

1. 申请 **MediaProjection**（录屏授权弹窗，用户必须手动同意）
2. 用该 MediaProjection 构造 **`AudioPlaybackCaptureConfiguration`**
3. 把它塞进 `AudioRecord.Builder.setAudioPlaybackCaptureConfig(...)`
4. 从 AudioRecord 读 PCM

需要的最低版本：**API 29（Android 10）**。这是我们 minSdk 定 29 的原因。

## 2. 失败矩阵（决定方案成败）

| 条件 | 结果 | 备注 |
|---|---|---|
| 目标 App 未禁止捕获，usage 属于 MEDIA/GAME/UNKNOWN | 可捕获 | 大部分视频/直播 App 属此类 |
| 目标 App 设置 `allowAudioPlaybackCapture=false` | **抓不到（静音）** | 系统级拦截，无解 |
| 内容被 DRM 保护 | **抓不到** | 常见于付费流媒体 |
| usage 为 `USAGE_VOICE_COMMUNICATION`（通话） | 抓不到 | 系统禁止 |
| 我们没把该 usage 加进匹配列表 | 抓不到 | 这是**我们自己的配置问题**，可修 |
| 目标 App 处于静音/耳机外放被系统拦截 | 抓不到 | 环境问题 |

**关键区分**：静音结果可能来自三种原因——目标 App 禁止、内容受保护、
或我们匹配规则没写全。探针只能告诉你"有没有声音"，不能告诉你"为什么没有"。
所以探针的输出要配一份检查清单（见第 4 节）。

## 3. 匹配规则写全一点

`AudioPlaybackCaptureConfiguration.Builder` 上可用的匹配条件：

- `addMatchingUsage(...)`：按用途匹配。建议全部列出：
  `USAGE_MEDIA`、`USAGE_GAME`、`USAGE_UNKNOWN`、`USAGE_ASSISTANT`、
  `USAGE_ASSISTANCE_NAVIGATION_GUIDANCE`（按需，会引入导航音）
- `addMatchingUid(...)`：只抓指定 App（更精准，避免抓到系统提示音）
  → 生产环境推荐：先列出正在播放的 App，让用户选一个，再按 UID 匹配
- `addDisallowedCapturePolicy(...)`：控制对"禁止捕获"App 的处理策略

**建议的默认配置**：先只匹配 `USAGE_MEDIA` + `USAGE_GAME` + `USAGE_UNKNOWN`，
确认能抓到之后，再改成按 UID 精准匹配，减少杂音。

## 4. 排查清单（探针报 0 时按顺序检查）

1. 目标 App 确实在出声？（先把系统音量调大，确认外放能听到）
2. 是否插了耳机/连了蓝牙？部分场景下路由不同，会影响捕获结果
3. 换一个 App 试（比如系统自带的音乐播放器）——如果它也抓不到，说明是我们的配置问题
4. 换成无版权争议的普通视频源试（排除 DRM）
5. 把 `addMatchingUsage` 全部列出，重试
6. 用 `AudioManager.getActivePlaybackConfigurations()` 看系统是否认为有活跃播放；
   有活跃播放但抓不到，基本可判定为"该 App 禁止捕获"

## 5. 降级方案（探针不通过时）

| 降级路线 | 做法 | 代价 |
|---|---|---|
| 麦克风同传 | 手机外放，用麦克风录进来再识别 | 音质受环境影响，会录入环境噪声；耳机场景不可用 |
| OCR 屏幕翻译 | 截屏识别画面上的字幕再翻译 | 需要目标内容本身有字幕；延迟更高 |
| 换源 | 换一个允许捕获的 App / 用网页版（浏览器内播放） | 受内容生态限制 |
| 只做"附近说话"同传 | 彻底放弃抓播放音频，转向面对面同传 | 与你的原始需求不符，但确定性最高 |

## 6. 版本相关的坑（待上机确认）

- **Android 14（API 34）起**：使用 MediaProjection 必须配合一个
  `foregroundServiceType="mediaProjection"` 的前台服务，且**要先启动前台服务，
  再调用 `getMediaProjection()`**，否则抛 `SecurityException`。
  本项目 `InterpreterService` 已按这个顺序写。
- API 34+ 还要求对 MediaProjection 注册 `registerCallback`。
- 部分国产 ROM 对录屏/音频捕获有额外限制或弹窗，需留意厂商策略。
